# Momento 1 - Web II

Proyecto desarrollado con **React + Vite** como parte del curso de Desarrollo Web II.  
Incluye un sistema de navegación, lista de usuarios en tarjetas y pie de página, todo con una paleta institucional.

---

##  Características
- Navbar con enlaces de navegación (Home, Servicios, Contacto).
- Footer con información institucional.
- Lista de 20 usuarios en tarjetas con:
  - Nombre y Apellido.
  - Profesión.
  - Avatar (incluye foto personalizada para Miguel Hernández).
  - Botón de acción "Contactar".
- Estilos consistentes con la paleta de colores institucional:
  - Azul: `#0033A0`
  - Amarillo: `#FFE946`
  - Turquesa: `#00AEC7`
  - Azul claro: `#4EC3E0`
  - Blanco: `#FFFFFF`
  - Amarillo secundario: `#E3E829`
